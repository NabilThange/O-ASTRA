# 3D Model Code Examples

This directory stores reusable code examples and templates for 3D modeling in Partwright Studio (`https://www.partwrightstudio.com/editor`).

## File Structure & Where to Paste Examples:
You can paste your custom 3D model code examples right here in this folder:
- `.opencode/skills/3d_model/examples/` (in your workspace: `c:\Users\thang\Downloads\bytebot-main\bytebot-main\.opencode\skills\3d_model\examples\`)

Suggested naming conventions:
- For JavaScript / Manifold scripts: `<model_name>.js`
- For OpenSCAD scripts: `<model_name>.scad`
- For BREP / Replicad scripts: `<model_name>.brep.js`

Aria reads these files directly when designing or referencing 3D models.
